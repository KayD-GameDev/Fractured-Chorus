# Fractured Chorus — Concept Art

## When to use

- Early exploration of Lumina, faction, weapon, or cinematic beat.
- Key art not yet tied to final sprite resolution.

## Steps

1. Read `.cursor/rules/fracture-chorus-art-style.mdc` for palette and mood.
2. If a character appears: load `CHARACTER_LOCK.md` + `character-consistency` skill checklist.
3. Output: one clear composition + callouts (palette hex, material reads: glass, neon rim, fabric).
4. Avoid finalizing micro-detail that contradicts later sprite scale (keep readable silhouette at small size).

## Outputs

- Prefer layered description over a single busy frame; name deliverables for pipeline (`concept_*_v1`).

## Rules

- `fracture-chorus-art-style.mdc`, `2d-asset-standards.mdc`.

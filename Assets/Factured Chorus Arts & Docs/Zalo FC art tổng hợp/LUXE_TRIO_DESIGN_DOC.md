## 2. Pipeline ba form (chung)

Mọi thành viên LUXE tuân grammar biến hình idol → boss (`BOSS_REFERENCE.md`):

```
[Form A] Lumina Idol          Beautiful · symmetry cao · không glitch
         ↓ trigger: lệch nhịp / im lặng hook / Vault mid-run
[Form B] Cadence Uncanny      Dark Spark Uniform · smile frozen · costume siết
         ↓ trigger: Elite floor / combat gate
[Form C] Boss / Elite         Subvert tội lỗi cá nhân → sinh học quá mức
```


| Quy tắc                   | Chi tiết                                                      |
| ------------------------- | ------------------------------------------------------------- |
| **Subvert, don't negate** | Méo điều idol **tự hào**, không phá bằng grotesque ngẫu nhiên |
| **Symmetry → broken**     | Lumina mirror-perfect → Cadence gãy nhẹ → Boss gãy mạnh       |
| **Costume fusion**        | Spark Uniform dính da; không cởi = không lệch choreo          |
| **Music as anatomy**      | Nốt, staff, metronome, chorus stack trở thành cơ thể          |
| **Beautiful horror**      | Vẫn lấp lánh Corrupted Gold + LED; ghê vì **quá đúng**        |


### Mapping form theo nhân vật


| Nhân vật  | Form A — Lumina      | Form B — Cadence        | Form C — Boss           |
| --------- | -------------------- | ----------------------- | ----------------------- |
| **Astra** | Spark Uniform center | Dark Spark Uncanny      | **Canticle Overgrowth** |
| **Mimi**  | Spark Uniform flank  | Dark Spark + Guitar-Axe | **The Pulse**           |
| **Kiki**  | Spark Uniform flank  | Dark Spark + dual axes  | **The Echo**            |

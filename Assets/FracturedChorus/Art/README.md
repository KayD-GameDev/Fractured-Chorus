# Art imports

| Subfolder | Content |
|-----------|---------|
| `Characters/` | Per-canon folders (`Coda`, `Ren`, `Charlotte`) — `Animation/Idle|Move|…`; see `Characters/README.md` |
| `Backgrounds/` | Combat / hub / event BGs |
| `UI/` | Timeline chrome, icons, frames |

**Before import:** asset must be listed in GitHub `docs/ASSET_INVENTORY.md` with license + owner.

Until approved art exists, combat uses **runtime placeholders** (colored sprites from bootstrap).
